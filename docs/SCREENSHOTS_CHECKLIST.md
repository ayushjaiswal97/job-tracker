# Portfolio screenshots checklist

Click "Load sample data" first so every screen has content. Use a 1440 px wide browser window for desktop shots and Chrome DevTools device mode (iPhone 12/14, 390 px) for mobile. Save PNGs in `docs/screenshots/` with the names below.

## Must-have (put these in the README)
- [ ] `01-dashboard.png`: dashboard with stat cards and both charts visible
- [ ] `02-jobs-list.png`: jobs page with the filter bar and at least 8 jobs
- [ ] `03-add-job-modal.png`: add job form open
- [ ] `04-login.png`: login page, desktop view with the left panel
- [ ] `05-mobile-dashboard.png`: dashboard at 390 px
- [ ] `06-mobile-jobs.png`: jobs list at 390 px

## Nice-to-have
- [ ] `07-signup-validation.png`: signup form showing field errors
- [ ] `08-filtered-view.png`: stage filter set to Interview with a search term typed
- [ ] `09-edit-job.png`: edit modal with data pre-filled
- [ ] `10-delete-confirm.png`: delete confirmation dialog
- [ ] `11-empty-state.png`: a new account's empty dashboard
- [ ] `12-devtools-localstorage.png`: DevTools Application tab showing the stored keys (great for explaining persistence)

## Capture tips
- Hide bookmarks bar and browser extensions; use a clean profile or a window with no personal tabs.
- Use a fake name and email such as "Demo User" in screenshots.
- Record one 20 to 30 second GIF or video: sign up, add a job, change its stage, watch the chart update. Embed it at the top of the README.
- Add the deployed link and 3 screenshots to your resume and LinkedIn Featured section.
